Complexity guide

Big-O estimates depend on the data structure and operation

mkdir / touch O(k + d) Path components plus searching the destination directory's children.
tree / find O(N) May visit every node in the traversed subtree.
cp / recursive rm O(S) S is the number of nodes in the copied or removed subtree.
undo (snapshots) O(N) Snapshot copying can traverse the full filesystem tree.

These are educational estimates, not measured timings. N = nodes visited, k = path components, d = entries examined in a directory, S = subtree nodes.
